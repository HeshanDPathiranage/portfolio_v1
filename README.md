# Personal portfolio

A single-page portfolio built with React 19, Vite, TypeScript, Tailwind CSS v4, Framer Motion, and Lucide React. All portfolio content lives locally in `src/data.ts`; there is no backend.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Personalize

Update `src/data.ts` with your own profile, project links, experience, and skills. Replace the sample social and contact details before publishing. The project cards currently use CSS-built artwork, so they work without image assets.
